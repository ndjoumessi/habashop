## 9. Commandes build (rappel)

```bash
cd /Users/nelson/Documents/Projets/habashop-mobile
export PATH="$HOME/.nvm/versions/node/v20.20.2/bin:$PATH"

# AAB Google Play (production)
eas build --platform android --profile production

# APK test (preview)
eas build --platform android --profile preview

# Télécharger + renommer l'artefact (URL hashée → renommage au download)
URL=$(eas build:list --platform android --profile production --limit 1 --json --non-interactive \
  | python3 -c 'import sys,json; a=json.load(sys.stdin)[0]["artifacts"]; print(a.get("applicationArchiveUrl") or a.get("buildUrl") or "")')
curl -fL -o HabaShop-Mobile-v1.2.0.aab "$URL"
```
